# Dataset

The Elliptic Bitcoin transaction dataset is not stored in this repository.

Download it from:
- https://www.kaggle.com/datasets/ellipticco/elliptic-data-set
- https://pytorch-geometric.readthedocs.io/en/2.7.0/generated/torch_geometric.datasets.EllipticBitcoinDataset.html

Check the source's terms before redistribution. Keep downloaded files local and update notebook/source paths to your own environment. Do not commit personal absolute paths, credentials, or raw data unless redistribution is explicitly permitted.
